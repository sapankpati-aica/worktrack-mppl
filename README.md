# WorkTrack - MPPL Office Tasks & Compliances

Run locally:
1. Double-click `run_windows.bat`
2. Open http://127.0.0.1:5000
3. Login: admin@office.local / admin123

Latest changes:
- Removed My Day from the main sidebar.
- Daily Update is now an open sheet with columns: Task, From Time, To Time, Work Status, Remarks.
- Assigned tasks are prefilled for each employee.
- Blank rows are available for unassigned/ad-hoc work.
- Saving Daily Update updates task status in real time.
- Daily report can be exported for management.
